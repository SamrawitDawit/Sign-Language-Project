# Repo Structure

## Annotated file tree

```
Sign-Language-Project/
│
├── data/                          ← data artifacts (committed)
│   ├── landmarks.npy              (63580, 63) float32 — normalized landmark vectors

│   ├── label_to_index.json        class name → int (28 classes, 0–27)
│   ├── landmark_metadata.csv      per-sample image path + label
│   └── failed_images.txt          images where MediaPipe found no hand (23,420 entries)
│
├── models/                        ← model files (committed)
│   ├── model.pt                   MLP PyTorch checkpoint (state_dict + input_dim + num_classes)
│   └── hand_landmarker.task       MediaPipe Hand Landmarker float16 model
│
├── notebooks/                     ← pipeline notebooks
│   └── asl_landmark_pipeline.ipynb  data download → MediaPipe extraction → splits (already run)
│
├── docs/                          ← findings and report assets
│   ├── data.md                    dataset facts, preprocessing description, split sizes
│   ├── model_results.md           model comparison table, per-class accuracy, limitations
│   ├── structure.md               this file — repo layout and design decisions
│   ├── confusion_matrix.png       28×28 heatmap (generated by evaluation.ipynb)
│   └── per_class_accuracy.png     per-class bar chart (generated by evaluation.ipynb)
│
├── preprocessing.py               normalize_landmarks() — wrist-center + scale normalize
├── train.py                       train MLP + RF; saves models/model.pt + results.json
├── infer.py                       predict(landmarks) → (letter, confidence); lazy-loads model
├── buffer.py                      SentenceBuffer — commit/space/backspace logic
├── demo.py                        webcam loop: MediaPipe → infer → buffer → display
│
├── evaluation.ipynb               confusion matrix, per-class accuracy, comparison table
├── results.json                   {"mlp": {...}, "rf": {...}} — filled by train.py
├── pyproject.toml                 uv project manifest — Python version + dependency list
├── uv.lock                        fully pinned lockfile (auto-generated, commit but do not edit)
└── README.md                      setup and usage instructions
```

## Data flow

```
Webcam frame
    │
    ▼
MediaPipe Hand Landmarker (models/hand_landmarker.task)
    │  results.hand_landmarks[0]  →  21 NormalizedLandmark objects
    ▼
np.array([[lm.x, lm.y, lm.z] ...])  →  shape (21, 3)
    │
    ▼
preprocessing.normalize_landmarks()
    │  1. wrist-center: coords -= coords[0]
    │  2. scale-normalize: coords /= max(||xy||)
    │  output: (63,) float32
    ▼
infer.predict()  →  (letter, confidence)
    │
    ▼
buffer.SentenceBuffer.update()
    │  hold 15 frames → commit letter
    │  no hand 20 frames → word space
    │  'del' class → backspace
    ▼
Sentence displayed on screen
```

## Module responsibilities

| Module | Responsibility | Consumed by |
|---|---|---|
| `preprocessing.py` | `normalize_landmarks()` — single source of truth for feature normalization | `train.py`, `infer.py` |
| `train.py` | Load splits, train MLP + RF, save checkpoint + metrics | run once |
| `infer.py` | Lazy-load model; `predict(landmarks) → (letter, confidence)` | `demo.py`, `evaluation.ipynb` |
| `buffer.py` | `SentenceBuffer` — frame-level predictions → committed sentence | `demo.py` |
| `demo.py` | Webcam loop, MediaPipe, overlay rendering | end user |
| `evaluation.ipynb` | Offline evaluation, plots, comparison table | report |

## Refactoring notes

### Directory reorganisation
The repo was reorganised after initial development. Original layout had all files at the root level. Files were moved into subdirectories as follows:

| File | From | To |
|---|---|---|
| `landmarks.npy`, `labels.npy`, `splits.npz`, `label_to_index.json`, `landmark_metadata.csv`, `failed_images.txt` | root | `data/` |
| `model.pt`, `hand_landmarker.task` | root | `models/` |
| `asl_landmark_pipeline.ipynb` | root | `notebooks/` |

Path references updated in `train.py`, `infer.py`, and `evaluation.ipynb` after the move. All imports verified working post-refactor.

### Package management — switch to uv
Dependencies are managed with [uv](https://docs.astral.sh/uv/) (replacing ad-hoc `pip install` calls). The full dependency list lives in `pyproject.toml`; exact pinned versions are in `uv.lock`.

```
pyproject.toml   declares requires-python and top-level dependencies
uv.lock          fully resolved, reproducible lockfile — commit this file
.venv/           local virtual environment created by uv sync — do not commit
```

To reproduce the environment on any machine:
```bash
uv sync          # creates .venv and installs everything from uv.lock
uv run python demo.py   # runs inside the venv without activating it
```

Dependencies: `torch`, `numpy`, `scikit-learn`, `mediapipe`, `matplotlib`, `seaborn`, `jupyter`, `nbconvert`, `ipykernel`.
